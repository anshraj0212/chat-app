# Talksy Mobile

Native React Native / Expo client for the existing Talksy Socket.IO backend.

## Run locally

```bash
cd mobile
npm install
npm start
```

Open it in Expo Go, or run:

```bash
npm run android
```

## Server URL

The app currently connects to:

```text
https://chat-app-g2ao.onrender.com
```

Change `SERVER_URL` in `App.js` if your Render URL changes.
